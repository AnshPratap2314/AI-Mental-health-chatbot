# MindCare Response Dataset v3

- 10,000 unique user messages
- 8,000 train / 1,000 validation / 1,000 test
- 20 intents, 500 examples each
- 0 exact message overlap across splits
- 200 unique response strings: 10 per intent
- Stable response style IDs shared across splits
- Stable mood/topic contract: one interpretable mood + topic per intent
- `high_risk` remains in the dataset for pipeline evaluation only; production safety responses remain deterministic and must never be generated by the normal response model.

The v3 dataset intentionally removes contradictory metadata labels from the previous synthetic set. This makes mood/topic routing learnable and reproducible instead of rewarding a noisy classifier.
